# 阶段 02｜扫描引擎与安全边界

AI Website Preflight · Codex 独立执行任务书

## 1. 本阶段目标

实现安全、可控的 URL 扫描基础能力，为后续规则提供统一证据。

## 2. Codex 执行任务

1. 实现 URL 规范化，只允许 HTTP/HTTPS。

1. 实现 SSRF 防护：拒绝 localhost、loopback、RFC1918、link-local、云 metadata 等地址；每次重定向后重新验证。

1. 设置连接/读取超时、最大响应体、最大重定向次数。

1. 抓取首页、robots.txt、sitemap.xml；从站内链接/sitemap 选择最多 5–10 个代表页面。

1. 保存扫描任务状态：queued/running/completed/failed。

1. 单 worker + 有限并发，适配 1GB RAM；单个页面失败不能拖垮整个扫描。

1. 收集 HTTP 状态、最终 URL、headers、HTML、链接、基础 TLS 信息等规则所需证据。

1. 完整源码只用于扫描过程，不长期保存。

## 3. 明确禁止

- 无限爬虫

- 扫描内网

- 执行目标站任意脚本/命令

- 高并发 Chromium

- 全站抓取

## 4. 验收标准

☐ 正常公开网站可以完成扫描。

☐ 私网/恶意 URL 被拒绝。

☐ 重定向到私网时被阻断。

☐ 超时、大页面、异常响应不会导致服务崩溃。

☐ 最多抓取设定数量页面。

☐ 扫描状态和错误信息可被结果页读取。
