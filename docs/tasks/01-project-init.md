# 阶段 01｜项目初始化与开发规范

AI Website Preflight · Codex 独立执行任务书

## 1. 本阶段目标

建立一个可持续开发、适合 1GB 云服务器部署的 MVP 项目骨架。此阶段不实现完整扫描功能。

## 2. Codex 执行任务

1. 使用 Next.js + TypeScript 建立项目；采用轻量 UI 方案，避免无必要依赖。

1. 建立首页基础结构：产品标题、URL 输入框、Run Preflight 按钮、示例结果区域；按钮此阶段可进入占位扫描流程。

1. 建立 /scan/[id]、/tools/... 的路由骨架。

1. 建立环境变量示例、基础日志、错误处理、健康检查接口。

1. 建立 SQLite 数据访问层的最小骨架，但不要设计复杂用户体系。

1. 在仓库根目录创建 AGENTS.md，写入产品边界、性能约束、安全要求和禁止事项。

1. 配置 lint、typecheck、build 和基础测试命令。

1. 提供 README：本地运行、构建、生产部署方式。

## 3. 明确禁止

- 登录/注册

- 支付/订阅

- AI API

- 复杂 Dashboard

- 团队功能

- 浏览器插件

- 自动修改 GitHub 仓库

## 4. 验收标准

☐ npm install 后可正常启动开发环境。

☐ lint、typecheck、build 全部通过。

☐ 首页和结果页骨架在桌面/移动端可正常显示。

☐ 代码目录清晰，没有为未来功能过度抽象。

☐ AGENTS.md 明确限制 Codex 不得自行扩大 MVP 范围。

## 5. 完成后必须汇报

- 本阶段实际完成了什么；列出主要文件/模块。

- 运行了哪些测试、lint、typecheck、build；结果是什么。

- 有哪些未完成项、已知问题或技术债。

- 是否自行改变了需求；如有，说明原因。

- 服务器/安全/性能方面发现了什么风险。

- 停止继续开发下一阶段，等待人工验收。

## 6. 给 Codex 的结束指令

完成本任务书后不要自动进入下一阶段，不要添加未要求的功能。先提交本阶段变更、测试结果和验收清单，等待确认。
